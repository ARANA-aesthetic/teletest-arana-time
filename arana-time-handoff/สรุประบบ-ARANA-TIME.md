## 2. ผู้ใช้งานในระบบ

| บทบาท | เข้าถึงอะไรได้ |
|---|---|
| **พนักงาน** | เช็กอิน/เอาท์, ยื่นใบลา, ขอ OT, ขอไปทำงานสาขาอื่น, ดูประวัติของตัวเอง |
| **ผู้จัดการ (manager)** | อนุมัติ/ปฏิเสธใบลาได้ |
| **HR** | ทุกอย่างของผู้จัดการ + จัดการพนักงาน/สาขา/ผู้บริหาร + ดูรายงาน + ตั้งค่าระบบ + อนุมัติ OT + อนุมัติคำขอเปลี่ยนใบหน้า |
| **เจ้าของ (owner)** | สิทธิ์เท่า HR |
| **แอดมิน (รหัสผ่านกลาง)** | สิทธิ์สูงสุด ใช้สร้างบัญชี HR คนแรก |

## 3. ฟีเจอร์หลัก

### 3.1 เช็กอิน–เช็กเอาท์ด้วยใบหน้า
- ต้องอยู่ในระยะพิกัด GPS ของสาขา (ยกเว้นวันที่อนุมัติให้ไปทำงานสาขาอื่น/นอกสถานที่)
- ยืนยันใบหน้าต้อง**ตรงกันต่อเนื่องหลายเฟรม** ก่อนถือว่าสำเร็จ (กันสวมสิทธิ์สแกนแทนกัน)
- คำนวณ "สายกี่นาที" อัตโนมัติจากเวลาเข้ากะของแต่ละคน
- **การเปลี่ยน/ลงทะเบียนใบหน้าใหม่ (หลังลงทะเบียนครั้งแรกไปแล้ว) ต้องรออนุมัติจาก HR ก่อนมีผล** — กันพนักงานให้คนอื่นสแกนหน้าแทนตัวเอง

### 3.2 ใบลา
รองรับ: ลาป่วย (มี/ไม่มีใบรับรองแพทย์), ลากิจ (หัก/ไม่หักเงิน), ลาพักร้อน, ลาประเพณี, ลาคลอด, และ **ลาเป็นชั่วโมง** (ป่วย/กิจ)
- แนบรูปหลักฐานได้ตอนยื่น หรือแนบเพิ่มภายหลัง
- แก้ไขข้อมูลใบลาได้เอง (ตอนยังไม่อนุมัติ) หรือขอแก้ไข (หลังอนุมัติแล้ว ต้องรออนุมัติซ้ำ)
- **HR แก้ไขข้อมูลใบลาได้โดยตรง** (ประเภท/วันที่/เหตุผล) กรณีพนักงานกรอกผิด — มีผลทันที ไม่ต้องรออนุมัติซ้ำ พร้อมคำนวณนาทีสายใหม่อัตโนมัติถ้าจำเป็น
- ลบคำขอที่ยื่นซ้ำ/ผิดพลาดได้ (ทั้งฝั่งพนักงานและ HR) โดยไม่ส่งแจ้งเตือนซ้ำเข้ากลุ่ม

### 3.3 OT (ทำงานล่วงเวลา)
- ขอพร้อมกันได้หลายคนในคำขอเดียว (เลือกจากรายชื่อเพื่อนร่วมสาขา)
- HR อนุมัติ/ปฏิเสธทั้งกลุ่มพร้อมกันได้

### 3.4 ไปทำงานสาขาอื่น / นอกสถานที่
- พนักงานยื่นขอเองได้ (เลือกสาขาจริง หรือ "ทำงานนอกสถานที่")
- ระบบจะข้าม GPS, ซ่อนเมนูปิดแอร์/ความสะอาด, และส่งแจ้งเตือนไปห้อง Telegram ของสาขาที่ไปทำงานแทนอัตโนมัติ
- **HR เพิ่มบันทึกย้อนหลังให้ได้** กรณีพนักงานยังไม่รู้จักเมนูนี้ แต่ไปทำงานนอกสถานที่จริง (ไม่นับขาดงาน ไม่คิดสาย)

### 3.5 ตรวจปิดแอร์ / ความสะอาด / ความเรียบร้อยพนักงาน
- พนักงานถ่ายรูปยืนยันแต่ละจุด/แต่ละวัน (บังคับถ่ายสดจากกล้อง ห้ามเลือกรูปเก่า)
- สรุปยอดที่ยังไม่ครบ ส่งเข้า Telegram อัตโนมัติทุกวัน 11:30 น. (ความสะอาด+ความเรียบร้อย) และ 23:00 น. (ปิดแอร์)
- พนักงานที่มีใบลาอนุมัติแล้วครอบคลุมวันนั้น จะไม่ถูกนับว่า "ไม่ได้ส่งตรวจ"

### 3.6 ลืมสแกน / เข้างานพิเศษ
- **ลืมสแกน**: HR เพิ่มเวลาเข้างานย้อนหลังให้ได้ (คิดสาย 30 นาทีคงที่ตามนโยบาย)
- **เข้างานพิเศษเฉพาะวัน**: กรณีเหตุสุดวิสัย (เช่นไฟดับ) ตั้งเวลาเข้างานใหม่เฉพาะวันนั้นได้ (ทั้งบริษัทหรือเฉพาะสาขา) พร้อมปุ่มคำนวณนาทีสายใหม่ให้คนที่สแกนไปแล้วก่อนตั้งค่า

### 3.7 ใบเตือนพนักงาน
- บันทึกข้อมูล + ออกเอกสาร PDF ตามฟอร์มบริษัท พร้อมเซ็นชื่อออนไลน์ได้ (พนักงาน/หัวหน้า/เจ้าของ) จากแท็บเล็ตเครื่องเดียว
- รองรับสลับชื่อ-โลโก้บริษัทในเครือ

### 3.8 รายงาน
- ตารางรายวัน: ขาด-ลา / มาสาย / OT (ทั้งเดือน แยกรายคน)
- ตารางสรุปเดือน: รวมทุกประเภทลา, นาทีสายรวม, ชั่วโมง OT
- ส่งออกเป็น Google Sheets ได้ (ปุ่มเดียว)
- พนักงานที่ลาเป็นชั่วโมง/ไปทำงานสาขาอื่น จะไม่ถูกนับว่าขาดงานผิดพลาด

### 3.9 วันหยุด
- วันหยุดบริษัท (ตั้งได้ทั้งปี, แยก "ตายตัว" กับ "ยืดหยุ่น" สำหรับลาประเพณี)
- วันหยุดประจำสัปดาห์ระดับสาขา (เช่น ทุกวันจันทร์)
- **วันหยุดประจำสัปดาห์เฉพาะรายบุคคล** (เช่น บางตำแหน่งไม่ต้องเข้าวันอาทิตย์ ขณะที่สาขายังเปิดปกติ)

### 3.10 การแจ้งเตือน Telegram (อัตโนมัติทุกวัน)
| เวลา | เนื้อหา |
|---|---|
| 10:30 | สรุปคนลา + คนมาสายวันนี้ |
| 11:30 | สรุปตรวจความสะอาด + ความเรียบร้อยพนักงาน |
| 14:00 | เช็กว่าคนลาเป็นชั่วโมงกลับมาเช็กอินครบไหม |
| 23:00 | สรุปปิดแอร์ |
| 23:30 | เตือนคนที่ยังไม่แนบหลักฐานใบลา |

## 4. ความปลอดภัยที่เพิ่มเข้ามา (สำคัญ)

1. **กันสแกนแทนกัน**: ต้องจับใบหน้าตรงกันต่อเนื่องหลายเฟรม (ไม่ใช่เฟรมเดียวผ่านทันที)
2. **กันเปลี่ยนใบหน้าโดยไม่ได้รับอนุญาต**: เปลี่ยนใบหน้าที่ลงทะเบียนใหม่ (หลังครั้งแรก) ต้องรอ HR อนุมัติก่อนมีผลจริง ใบหน้าเดิมยังใช้สแกนได้ตามปกติระหว่างรออนุมัติ
3. ระบบ audit log บันทึกทุกการอนุมัติ/ปฏิเสธ/แก้ไข/ลบที่สำคัญ ดูย้อนหลังได้จากหน้าตั้งค่า

## 5. จุดที่ HR ควรรู้ (ทางลัดที่มีให้ใช้เอง ไม่ต้องรอทีมพัฒนา)

- **แก้ข้อมูลใบลาที่กรอกผิด** → หน้าอนุมัติ → ประวัติใบลาทั้งหมด → ปุ่ม "แก้ไข"
- **ลบคำขอที่ยื่นซ้ำ** → ปุ่มถังขยะข้างปุ่มอนุมัติ/ปฏิเสธ (ไม่แจ้งเตือนกลุ่มไหนเลย)
- **พนักงานไปนอกสถานที่แต่ยังไม่รู้จักเมนู** → แท็บตรวจ → ปุ่ม "ทำงานนอกสถานที่"
- **ไฟดับ/เหตุสุดวิสัย ต้องปรับเวลาเข้างาน** → ตั้งค่า → เกณฑ์สาย/ขาด → "เข้างานพิเศษเฉพาะวัน"
- **บางตำแหน่งไม่ต้องเข้าวันอาทิตย์** → ตั้งค่า → พนักงาน → แก้ไข → ติ๊กวันหยุดประจำสัปดาห์ของคนนั้น
